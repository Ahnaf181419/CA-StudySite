# Architecture Study Atlas

A static computer architecture exam study site with six chapters, worked examples, diagrams, exam practice, lecture slides, and handwritten revision notes.

## Run locally

```sh
python3 -m http.server 8000
```

Open http://localhost:8000 in your browser. Chapter completion is stored in that browser.
